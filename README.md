Список задач — это десктопное приложение с графическим интерфейсом, созданное на языке Python с использованием библиотеки Tkinter. Оно предназначено для удобного управления повседневными задачами: пользователь может добавлять новые дела, отмечать их как выполненные, удалять по одному или группами, а также отслеживать прогресс через встроенный счётчик и прогресс-бар. Все задачи автоматически сохраняются в файл tasks.json, что позволяет не терять данные после закрытия программы. Приложение выполнено в стиле киберпанк с тёмной темой и неоновыми акцентами. Код покрыт тестами для проверки корректности работы.
